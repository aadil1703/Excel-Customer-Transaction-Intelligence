# 📊 Customer Transaction Intelligence & Sales Analysis Dashboard

## 📌 Project Overview

The **Customer Transaction Intelligence & Sales Analysis Dashboard** is an advanced Microsoft Excel project designed to analyze customer transactions, evaluate sales performance, identify valuable customers, and generate meaningful business insights.

This project demonstrates practical Excel skills through data preparation, advanced formulas, PivotTables, PivotCharts, interactive slicers, timelines, What-If Analysis, Scenario Manager, Goal Seek, and Linear Regression.

The main objective is to transform raw transaction data into an interactive reporting solution that helps understand business performance and supports data-driven decision-making.

---

## 🎯 Project Objectives

- Analyze customer transaction data and sales performance.
- Identify top-performing products and high-value customers.
- Compare revenue across different regions.
- Analyze monthly sales trends.
- Build interactive dashboards using PivotTables and PivotCharts.
- Apply advanced Excel formulas and functions.
- Perform business scenario analysis using What-If Analysis.
- Understand regression analysis using Excel's Data Analysis ToolPak.

---

## 📁 Workbook Structure

The workbook contains the following worksheets:

| Sheet Name | Description |
|---|---|
| **Raw Data** | Original customer transaction dataset containing transaction details. |
| **Data Preparation** | Data cleaning, transformation, date handling, and preparation for analysis. |
| **Dashboard** | Interactive dashboard displaying KPIs, top customers, top products, and regional sales. |
| **Pivot Tables** | Actual PivotTables used to summarize revenue, product performance, monthly sales, customers, and quantities sold. |
| **What-If Analysis** | Business assumptions and calculations for revenue, costs, profit, and profit margin. |
| **Scenario Summary** | Comparison of Base Case, Best Case, and Worst Case business scenarios. |
| **Regression Analysis** | Worksheet containing independent and dependent variables for linear regression. |
| **Regression Cal (Calculation)** | Supporting regression calculations and analysis. |

## 🛠️ Excel Concepts & Features Used

### 1. Data Preparation
- Data organization and formatting.
- Date and time functions.
- Data validation and preparation.
- Duplicate and missing-value checks.
- Timestamp generation.

### 2. Advanced Excel Formulas
- `TODAY()`
- `NOW()`
- `DATEDIF()`
- `EOMONTH()`
- `FILTER()`
- `INDEX()` and `MATCH()`
- `COUNTIF()` and `COUNTIFS()`
- `SUMIF()` and `SUMIFS()`
- `TEXTBEFORE()` and `TEXTAFTER()`
- `IF()` and nested conditions.
- Dynamic array formulas.
- Customer and product analysis.

### 3. Conditional Formatting
- Data bars.
- Color-based formatting.
- Icon sets and directional indicators.
- Visual identification of important values.

### 4. PivotTables & PivotCharts

Created actual PivotTables to analyze:

- Revenue by Region.
- Revenue by Product.
- Monthly Revenue Trends.
- Revenue by Customer.
- Product Quantity Analysis.

Created three PivotCharts:

- Bar Chart – Revenue by Region.
- Pie Chart – Revenue by Product.
- Line Chart – Monthly Revenue Trends.

### 5. Interactive Dashboard

The dashboard includes:

- Total Revenue.
- Total Transactions.
- Unique Customers.
- Average Transaction Value.
- Top 10 Customers.
- Top Products by Units Sold.
- Regional Sales Performance.
- Interactive Region and Product Slicers.
- Date Timeline for period-based filtering.

### 6. What-If Analysis

Applied Excel's business analysis tools:

**Scenario Manager**
- Base Case.
- Best Case.
- Worst Case.
- Scenario Summary Report.

**Goal Seek**

Used Goal Seek to calculate the required number of units sold to achieve a target projected profit of $50,000.

### 7. Linear Regression Analysis

Used Excel's Data Analysis ToolPak to explore the relationship between:

- Independent Variable (X): Quantity.
- Dependent Variable (Y): Total Amount.

The regression exercise demonstrates regression statistics, R-squared, coefficients, and statistical significance.

*Note: Quantity and Total Amount are influenced by product pricing, so this regression is primarily a demonstration of the ToolPak rather than a validated causal or forecasting model.*
